# Portfolio Bha3.in

## Live PyPI download count

The About section reads the public lifetime-download badge for `fastapi-querybuilder` from pepy.tech. The badge is cached by pepy.tech for 12 hours. The site displays its numeric value in the stat card and falls back to the badge (or a link to the live stats page) if the value cannot be read. No API key or scheduled rebuild is needed.

Static metadata and the downloadable PDF resume link to the live statistics instead of embedding a download total that would become stale.
